# 原型说明 —— 怎么从 `server.mjs.reference` 提取进件后端

> `server.mjs.reference` 是 steward 的**完整** server.mjs 快照（零依赖 Node `http` 服务）。它里面**大部分是 steward 自己的东西**（ttyd/tmux 内嵌终端、claude/codex 引擎、窗口管理、飞书、board 等），**收件只需要其中的"进件 + 模型 API"这一小块**。下面列出要搬的部分，其余全部丢弃。

## 要提取的 HTTP 端点（在 reference 里搜路径字符串）
| 端点 | 方法 | 作用 |
|---|---|---|
| `/api/model-config` | GET | 读模型配置（**key 掩码**，云端可达也安全） |
| `/api/model-config-save` | POST | 存模型配置（provider/apiKey/model/baseUrl） |
| `/api/model-test` | POST | 测试模型连通 |
| `/api/intake-submit` | POST | 表单提交需求/BUG → 写盘 → AI 首轮沟通 |
| `/api/intake-reply` | POST | 提交人回复 AI 的澄清 → AI 继续 |
| `/api/intake-list` | GET | 某项目进件列表 |
| `/api/intake-detail` | GET | 单条进件详情 |
| `/api/intake-chat` | POST | （纯对话版遗留）AI 主导追问、输出 record 块归档，可留作参考 |
| `/api/spec-modules` | GET | 某项目 spec 模块清单（表单模块下拉/联想） |
| `/api/projects` | GET | 项目清单 —— **收件里要改**：应是"进件服务已知的项目"，不是 steward 注册表 |

## 要提取的辅助函数（在 reference 里搜函数名）
- **模型 API**：`callModel(cfg, {system, messages, maxTokens})`（支持 anthropic `/v1/messages` + openai `/v1/chat/completions`）、`readModelCfg` / `writeModelCfg` / `maskKey`、常量 `MODEL_CFG_FILE`。
- **进件**：`intakeDir(proj)`、`specIndex(proj)`（给 AI 的 spec 模块上下文）、`intakeGenId`（`XQ-`/`BUG-YYYYMMDD-NN`）、`yamlEsc`、`renderIntakeMd(e)`（frontmatter + 正文 + 沟通记录 + AI 处理意见）、`saveIntake` / `loadIntake` / `listIntake`、`intakeSystem`、`intakeAI`、`intakeChatSystem(proj)`。

## 搬运时要改的地方（去 steward 耦合 + 落地新架构）
1. **落盘位置**：`intakeDir` 现在是 `<proj.path>/docs/intake/`。收件要改成 **intake-store**（先本地一个目录、按 project 分子目录，见 架构设计.md §5）。
2. **项目来源**：`/api/projects` 现在读 steward 的 `~/.steward/projects.json`。收件要用**自己的项目登记**（它 clone/mirror 了哪些项目代码仓）。
3. **模型配置路径**：`MODEL_CFG_FILE` 现在在 `~/.steward/model-api.json`。收件改成自己的配置目录，**别复用 steward 的**。
4. **新增 `version` + `site`**：`intake-submit` 入参、`renderIntakeMd` frontmatter、列表都要带（架构设计.md §6）。
5. **代码仓只读上下文**：`specIndex` 现在读本地 `docs/specs/`；收件要能读 **`spec@tag`**（`git show <tag>:docs/specs/**`）以喂"该版本"的上下文。
6. **前端**：`submit.html` / `model-config.html` 直接可用；`submit.html` 要加 `?project=&site=&ver=&type=` 预填锁定，并把系统下拉/模块联想指向收件自己的 `/api/*`。

## 前端原型现状
- `submit.html`：选类型（需求/BUG）→ 填对应表单 → 提交后右侧 AI 沟通建议；医疗蓝设计 token；Tabler icon（`vendor/tabler/`）。
- `model-config.html`：provider（anthropic / openai 兼容）+ apiKey + model + baseUrl + 保存/测试连通；已对齐医疗蓝。
