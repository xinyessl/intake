# CHG · 咨询转述归因证据边界

- 日期：2026-08-14
- 关联 Spec：FS-04 AC-78
- 类型：回归边界补全

## 现象

生产可见 Chrome 的 Q127 将医院电话里的“对接方当数字传、长号码开始丢位”同时当成现象与已核因果，继续外推“可能丢精度”“发生在更上游（生成号、Excel、中间系统）”，并在只读核对后建议修改传参方式。

## 修复

- 电话/现场转述、怀疑、感觉或“好像”仅作为待核线索，不能支持概率或确定因果 claim。
- 裸“可能”与故障结果之间即使夹有“在途中”等位置状语，也进入同一 claim 证据门。
- 无逐层证据的上游、生成号、Excel、中间系统定位触发修订；未点名机制同时进入 scope 审计。
- “核对清楚后修改传参方式”纳入跨主体与直接副作用门；无完整受控条件时删除。

## 回归

- 固化 Q127 r28 完整生产绕行句式，验证概率、定位、scope 与动作四类违规同时可见。
- 安全降级只保留字段契约及已有原始报文的只读对比；待核线索与同一 claim 权威统计作为正例。
