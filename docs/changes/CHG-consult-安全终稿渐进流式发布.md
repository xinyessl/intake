# CHG · 咨询安全终稿渐进流式发布

- **日期**：2026-08-14
- **关联 spec**：FS-04 AC-73（行为边界补充，待人验收）
- **类型**：咨询输出体验与发布安全链路修复

## 现象

发布前语义审计为了防止草稿泄漏，必须先在服务端收齐完整模型答案。旧链路在审计/修订/降级后将终稿作为单个 `v` 事件整段推送，UI 等待后一次性出现全文，看起来不是流式。

## 修复

- 保留“完整草稿 → 确定性审计 → 最多一次修订 → 安全降级”服务端内部链路，草稿/修订稿不向 SSE 正文写入任何片段。
- 新增终稿结构分块：普通文字优先在自然句和换行边界切分；围栏代码、Markdown 管道表格、行内代码与链接作为不可拆原子块。所有 `v` 拼接后与安全终稿逐字相同。
- 安全终稿块之间使用短间隔，两套现有咨询客户端按多个 `v` 累计并重绘 Markdown，非 consult 端点不变。
- 终稿流式期间停止/断连立即停止后续块；只持久化已发送的安全前缀。`retrieval.answerStream` 与 `done.answerStream` 留存块数与完成态，不含草稿或修订稿原文。

## 验证

`tools/fs-04-consult-safe-final-stream.logic.test.mjs` 覆盖多块拼接、Markdown 结构不拆、审计失败仅流安全终稿、客户端停止/断连、两套客户端累计与非 consult 隔离。未改数据库表列、PWRS 业务代码或非咨询端点。
