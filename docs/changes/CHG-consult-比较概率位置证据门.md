# CHG · 咨询终稿比较概率位置证据门

## 现象

生产可见 Chrome 复测中，回答已经限定“请求已发、后端具体路径未知”，仍在条件分支写出“丢位更可能在请求之后”。电话转述和单一请求观测不能支持这一位置排序。

## 修复

- “更可能/较可能/比较可能在、从、由某位置”进入逐 claim 概率证据审计，不再依赖“发生/导致”等显式故障动词。
- 无直接证据时一次修订，仍失败则删除完整比较句，保留已核契约、当前观察与局部未知。
- A=B 且 C≠B 等逐层观测已经确认时，允许直接陈述确定边界，不用概率词。

## 证据

`tools/fs-04-consult-conversation.logic.test.mjs` 覆盖三种比较位置句、生产失败组合、安全降级二次审计和有序观测正例。
