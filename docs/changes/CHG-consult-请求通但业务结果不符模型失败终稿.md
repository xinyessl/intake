# CHG · 请求通但业务结果不符模型失败终稿

- **日期**：2026-08-31
- **来源**：浏览器正式测试 Q0820。问题询问“请求已通但业务结果仍不符合预期，下一步重点对照哪一层”；模型长度截断后系统却机械发布完整路由事实，没有给出分层排查顺序。
- **类型**：纯缺陷修复；业务职责、外部边界和排查安全边界不变，因此不修改 spec。

## 改动

- 模型失败时优先发布当前路由范围内的确定性分层诊断，不再机械搬运整张事实清单。
- 依次固定同次请求响应、对照已核职责与边界、核对路由已定义的只读实施证据，并在首次差异或证据缺口处停止。
- 明确“请求通”不等于业务结果正确；禁止重放、重试、修改数据或触发其他写操作。
- 不补写未定义的接口、表、按钮、状态或通用页面排查模板。
