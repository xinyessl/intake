# CHG · tag35 当前裁决优先与单一事实止答

- 日期：2026-08-14
- 规格：FS-04 AC-56
- 类型：事实源、检索与回答边界回归修复

## 现象

PWRS A06 已给出当前院区裁决，但同一 Markdown 内仍保留可检索的旧“账号授权院区集合”方案；旧模块又可能只列 `patientId + visitId`。模型因此会在后续诊断中混用废止规则，或在仅问一个数据库字段类型时主动扩写身份元组、索引和约束。

## 修复

1. 检索层支持 `RETRIEVAL-EXCLUDE-START/END` 审计区段：原文保留，目录、标识符与正文证据均剔除。
2. normal/deep 与运行时增加当前裁决优先守卫：现行 route/Spec 事实压过历史、遗留接口、账号差异及 assistant 自由文本。
3. 增加单一事实止答守卫：短字段类型/值/是非题不主动引入相邻列、身份元组、索引、约束、SQL 或相邻模块。
4. 会话显式新实体识别补充数据库表/字段/类型词族，避免患者身份主题抢占字段类型新问题。
5. PWRS 地图用现行反事实覆盖废止院区授权，并把患者相关请求统一到 `hospitalId + patientId + visitId`。

## 数据与接口

未改数据库、业务接口或 PWRS 业务代码；只调整文档检索、咨询提示/守卫、规格与模块地图。
