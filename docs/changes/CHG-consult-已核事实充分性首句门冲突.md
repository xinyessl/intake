# CHG：已核事实终稿不再被证据充分性首句门覆盖

- 日期：2026-08-26
- 类型：纯 Bug 修复，现有 Spec 行为不变
- 关联：`FS-04` 答疑发布前语义审计

## 现象

Audit 第 185 题已命中 `AUD-QR-GUIDE-01` 并提供完整 `verifiedFacts`，但生产最终发布了通用“最小缺口”模板，出现 `current route`、本机日期星期和页面刷新等无关内容。

## 根因

已核事实第一条先回答“提交成功不等于审核闭环”，截图是否足够在第二条回答。通用证据充分性审计只认可第一句中的“够/不够”，把逐行已核终稿误判为缺少结论；两轮确定性兜底仍被同一门拦截后，第三轮退回普通诊断模板。

## 修复

- `fallbackMode` 同时保留在路由结果顶层和内部卡片，审计任一路径均可识别已核事实发布策略。
- 仅当终稿逐行逐序等于全部 route facts，且 facts 内已有明确证据充分性结论时，允许总业务结论先于截图结论；普通模型草稿仍须第一句直答。
- 恢复层继续优先重建全部 verified facts，不再改用通用诊断模板。
- 通用模板删除 `current route` 内部措辞，并且不再把一般“请求时间/发生时间”解释成本机日期星期主题。
- 生产诊断元数据增加 `routeFallbackMode` 与 `verifiedFactsFallback`，便于直接确认发布策略是否生效。

## 验证

- 第 185 题原问回归：业务结论、同一次请求证据、关联日志、分层判定和禁止重发真实患者 XML 全部保留。
- 终稿不得包含 `current route`、最小缺口、本机日期星期或附件内容臆读。
- 路由发布策略顶层与卡片内双通道均有测试；普通 route 不得误开启。
- 修复后终稿再次进入相同语义审计，结果必须为零违规。
