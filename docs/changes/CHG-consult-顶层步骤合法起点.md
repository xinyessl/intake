# CHG · 咨询终稿顶层步骤合法起点

- 日期：2026-08-14
- 关联 Spec：FS-04 AC-101
- 类型：生成后发布前结构防回归

## 变更

- 顶层阿拉伯数字步骤默认从 `1` 开始，内部连续的 `3/4/5` 不再被当成完整新清单。
- 只有用户当前问题明确提到“第 N 步/做到第 N 步”时，才允许答案从 `N` 重述或 `N+1` 承接。
- fallback 仅从本轮合法起点连续重编号已有完整步骤，不新增缺失步骤正文。

## 原因

生产可见 Chrome 复测中，截图证据题的新清单直接从 `3` 开始。上一轮 assistant 的编号不能作为用户已完成前序步骤的事实，必须由本轮用户原文明示才可承接。
