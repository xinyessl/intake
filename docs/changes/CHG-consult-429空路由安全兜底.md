# CHG · 答疑 429 空路由安全兜底

- **日期**：2026-08-31
- **来源**：生产请求 `3b9247d136`、`0c4d5398d8`、`ca9b995025` 在模型返回 HTTP 429 后，空路由兜底继续读取 `answerFacts`，前端只能显示通用处理异常。
- **类型**：纯缺陷修复；既有“无直接业务证据不得给出具体操作”的规则不变，因此不修改 spec。

## 改动

- `route=null` 或未命中时不再进入 matched-operation fallback。
- 使用明确的空路由安全审计对象处理诊断题和高风险操作题；收费发起、撤销等问法只允许发布无具体操作步骤的安全停点。
- 增加 `route=null + HTTP 429 + 怎么发起收费` 回归测试，断言不读取空对象、不伪造收费接口或写操作。
