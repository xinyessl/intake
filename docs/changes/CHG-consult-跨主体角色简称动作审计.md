# CHG · 咨询终稿跨主体角色简称动作审计

## 现象

生产可见 Chrome 复测中，回答前半段已要求只读核已有报文，末尾仍写出“优先让对接按字符串传完整号”。既有守卫覆盖“对接方”，但“对接”简称和其它组织角色可绕过。

## 修复

- 发布前动作审计统一覆盖对接/对接方、接口方、第三方、厂商、供应商、院方、运维与开发。
- 按字符串、文本或指定格式发送，以及修改字段、编码、协议、映射和配置，仍须完整受控条件；否则整句删除。
- 否定动作、既有报文只读核对和完整受控条件齐备后的条件式验证作为正例，避免宽泛关键词误伤。

## 证据

`tools/fs-04-consult-conversation.logic.test.mjs` 增加多角色自然变体、生产失败原句、否定句和完整受控条件回归。
