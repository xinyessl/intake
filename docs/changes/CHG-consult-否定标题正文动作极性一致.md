# CHG：咨询终稿审计否定标题与正文动作极性

- 日期：2026-08-14
- 关联 Spec：FS-04 AC-91
- 类型：缺陷修复 + 回归边界补全

## 变更

发布前结构审计新增标题/正文极性检查。“不要做、禁止、避免、切勿”等否定标题下若只剩未被否定的正向许可、建议或帮助语句，触发一次全文修订；安全替代动作须移入独立正向标题，修订失败删除整组。

## 原因

生产可见复测中，“不要做的”标题下只剩“把截图值直接回我，我可以帮你判断”，标题与正文相反。既有动作、Markdown 与语法审计均无法发现这种文档级语义冲突。

## 回归

`tools/fs-04-consult-conversation.logic.test.mjs` 覆盖否定标题加正向建议、明确否定项、否定标题管辖的裸动作清单和正向标题下安全动作。
