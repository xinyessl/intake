# CHG · 咨询有序观测点一致性

- 日期：2026-08-14
- 关联 Spec：FS-04 AC-79
- 类型：回归边界补全

## 现象

生产可见 Chrome 的 Q129 已确认“报文是字符串但与原始全号不一致”，答案却继续说“问题可能在发出后的链路”，把已出现差异的观测点反向定位到该点之后。

## 修复

- 发布前新增有序观测点一致性审计，覆盖请求、报文、响应、收到值、落库值与页面展示。
- 某观测点已与原始/前一层不同，只允许说差异在该点已存在或不晚于该点；不得定位到该点之后。
- 仅前一点仍相等、后一点才不同时，允许把差异边界收敛到两点之间。
- 矛盾自然句或 Markdown 表格数据行触发一次修订；修订仍失败时删除完整句/整行。

## 回归

- 固化 Q129 r29 生产表格反向归因。
- 正例覆盖安全观测边界、合法两点区间与逐层值不可见时的局部未知。
