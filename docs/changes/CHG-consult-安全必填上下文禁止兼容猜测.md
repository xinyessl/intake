# CHG · consult 安全必填上下文禁止兼容猜测

## 背景

tag33 浏览器 1000 题 Q90 已正确命中 PWRS `DQ-003` 并回答患者三元身份键，但随后无证据补充“旧深链缺院区会兼容”和本地唯一约束，直接放宽了缺 `hospitalId` 必须拒绝的安全边界。

## 通用修复

- normal/deep 默认提示词增加“安全必填上下文不得靠兼容猜测补齐”：身份键、租户键、医院/院区上下文缺失时，必须按已核契约拒绝或提示回到可信入口重选。
- `/api/consult` 增加运行时 `consultCriticalContextGuard`；即使生产使用外置提示词，也会阻止模型自行声称历史链接兼容、自动补齐或从 token、默认租户/院区、相邻路由字段回退。
- 未覆盖的旧链接处理、本地唯一约束、缓存/数据库规则和自动映射保持局部未知，不得编造成事实来推翻 route `answerFacts`/`mustNotConfuse`。
- PWRS `DQ-003` 补齐患者三元身份键、缺 `hospitalId` 拒绝重选、历史深链/旧链接/收藏链接不回退、`districtCode` 仅限可信内部上游路由的正反事实与自然问法。
- 回归覆盖 Q90、历史链接、token/默认院区/`districtCode`、通用租户上下文、同主题继承和显式登录新实体切题。

## 影响边界

- 不修改 PWRS 业务代码、接口或数据库，只增强答疑提示契约、运行时事实守卫和说明书路由地图。
- 已有明确证据的真实兼容策略仍可照实回答；本规则仅阻止无证据兼容猜测。
- 无持久层变更，真库烟测不适用；生产验收以外置提示词核验、health 与官方 Chrome 可见 UI 为准。
