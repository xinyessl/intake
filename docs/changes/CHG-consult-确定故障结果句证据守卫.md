# CHG · 咨询终稿确定故障结果句证据守卫

- 日期：2026-08-14
- 关联 Spec：FS-04 AC-77
- 类型：回归边界补全

## 现象

生产可见 Chrome 的 Q127 在观测层定位守卫上线后，改写为“当数字传时会出现少位、丢精度或对不上”“裸数字就是会丢位的写法”。这些句子不再使用“直接/必然/发生在某层”，但仍把字段存储类型无证据外推成传输故障的确定因果。

## 修复

- 发布前 claim 级审计新增“会/就会出现、导致、造成故障结果”及“就是会故障的写法/类型/格式/传法”结构。
- 无同一 claim 的 route/Spec/源码确定规则时触发一次全文修订，仍失败则删除完整因果句；保留字段事实与既有报文只读对比。
- 修订提示要求当前只诊断一个字段/对象时不借技术依据枚举同表其它未问字段。
- 否定故障句和权威确定规则作为放行正例，避免静态删词误伤。

## 回归

- 固化 Q127 r27 的两种生产绕行句式。
- 覆盖安全降级后二次审计、否定句和权威规则放行。
