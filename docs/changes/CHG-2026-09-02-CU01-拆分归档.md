## 数据契约核对（重点：客户/医院到底是文件还是表）
- **客户 / 医院台账 = 文件 `data/customers.json`**（`{customers:[...]}`，server.mjs `loadCustomers/saveCustomers` L294-295），**不是 MySQL 表**。真库 `db.mjs init()` 只有 5 表（projects/accounts/sessions/intakes/kb_entries），**无 `customers` 表**（P0 §A.1/§A.2 + 原 spec「连本地真库 SHOW TABLES 已确认」核实）。是否迁库 = NEEDS-HUMAN（导读 §5 待决策 1）。
- 字段全景逐条对照 server.mjs `normCustomer`（L428-452）/ `normProduct`（L413-427）/ `custWithTicketCount`（L506-511）/ `deriveImpl`（L477-480）核过，**未臆造字段**。
- `impl` 读时派生自 `accounts.sites`（真库现有列，未加列）；`ticketCount` 派生自 `intakes.site`（真库现有 `VARCHAR(80)` 列）；激活为纯计算不落库不写盘。
