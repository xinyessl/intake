# CHG：实施端刷新恢复与全览宽屏重设计

- 日期：2026-08-10
- 关联：FS-04 AC-20/23/26，FS-09 AC-10
- 性质：行为修复 + 界面信息架构调整（无接口/数据口径/库结构变更）

## 变更

1. `public/field.html` 的 `sessionStorage` 草稿增加导航上下文和左侧选中态，刷新时按「引用数据 → 权限/存在性校验 → 对应视图加载 → 对话恢复」执行。医院/项目/系统越权或已删除时回退现有默认；版本列表就绪后二次校验并回退最新。
2. 切换 mode/医院/子项目/系统/版本/`groupBy` 立即存草稿。「新对话」只清当前对话，保留导航；退出登录才清会话桶与整份草稿。草稿不存登录密码/token。
3. 全览不改 `GET /api/field/overview` 及真实聚合口径。布局改为 1720px 上限的 `auto-fit` 网格，卡片少时折叠空轨道，1280px 三列、小屏一列。KPI 与卡片用明文标出待办；医院/产品版本改成可限高滚动的关联列表，医院卡改为有焦点态的原生按钮。
4. 未引入 URL hash/query：当前页是无路由的独立工作台，往 URL 写医院/系统名会扩大暴露面且与现有返回键语义冲突；本次依需求使用同标签 `sessionStorage` 完成。
