# CHG：咨询终稿统一审计表格与清单结构基数

- 日期：2026-08-14
- 关联 Spec：FS-04 AC-89
- 类型：缺陷修复 + 回归边界补全

## 变更

发布前结构一致性审计从按行表格扩展到 Markdown 清单，并覆盖“边、项、份、件、条、处、个”等结构数量声明。明确“对照边/对照项/观测点”表头按数据行计数；只有真正横向列项的表格才允许用列数满足声明。若修订失败，删除声明和对应完整结构，不补造缺失内容。

## 原因

生产可见复测中，答案声称对照两份原文、核两件事，却分别只生成一条表格数据和一个清单项。原有规则遗漏清单计数，且把两列表头误当成“两份”横向内容。

## 回归

`tools/fs-04-consult-conversation.logic.test.mjs` 覆盖表格与清单同时缺项、完整两项清单、横向同数表及普通“两条历史记录”叙述。
