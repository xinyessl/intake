# CHG · consult 观测不得用箭头升级为确定根因

- 日期：2026-08-25
- 类型：纯 bug 修复（现有 Spec 证据边界已正确）
- 范围：consult 发布前确定性因果审计与安全 fallback

## 根因

旧审计能拦截概率词和部分“发生在某层”写法，但没有完整覆盖“观测 → 多个具体根因”、“所以/因此”、“属…问题”和“定位为…”。二次修订进入 fallback 后，这些不带旧概率关键词的定性归因可以漏过终审。

## 修复

- 将箭头、因果连词、具体层/组件定位、“属…问题”和多候选打包归类纳入通用确定性因果审计。
- “日志无记录 → 动作未发生”按观测缺失反向定论拦截。
- 明确的待验证假设/可能分支不误拦；用户、current route 或本轮正文的原始日志/异常堆栈已确证同一根因时放行。
- fallback 删除无证据定论，收口为不排序待验证分支，明确需要原始日志或异常堆栈才能定位。

## 回归

- 生产 Q0005 两句必须命中因果审计。
- 日志缺失不得证明未消费/未执行。
- 待验证分支、纯观测边界和原始日志确证根因必须放行。
- 工作台/状态流转的同类根因跳跃同样必须拦截。
- fallback 不得保留原定论，且重审必须全绿。
