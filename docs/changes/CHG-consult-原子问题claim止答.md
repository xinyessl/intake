# CHG · 咨询原子问题 claim 止答

- 日期：2026-08-14
- 关联 Spec：FS-04 AC-100
- 类型：生成后发布前事实范围防回归

## 变更

- 单一接口/路径题只保留方法、当前 route 唯一已核精确路径与必要防混淆，删除未问的响应字段、参数、数据来源和 JVM/时区扩写。
- 单一字段类型/长度题只保留目标字段与所问属性，删除身份元组、缓存键、索引、约束等相邻实现。
- 若清理夹带扩写的整句同时移除了唯一主接口，安全 fallback 从当前 route 的唯一 answerFact 恢复精确方法+路径；不从草稿里的缩写或错误路径猜测。
- 显式多子问、为什么/排查/现场/验证等诊断意图继续走完整事实与安全动作链，不触发原子止答。

## 原因

生产可见 Chrome 复测中，原子“调用哪个接口”题虽答对接口，却又追加响应字段和 JVM 时区。事实真实性不能替代问题范围，实施需要的是直接、稳定、不过量的答案。
