# CHG · consult 受限证据不得反向否定未观测下游

- 日期：2026-08-25
- 类型：纯 bug 修复（现有 spec 已要求 unknown/unverified 不得写成肯定或否定结论，不改 spec）
- 范围：`/api/consult` 发布前语义审计、一次修订提示与确定性安全降级

## 现象

生产问题明确只有一次既有请求和响应、无数据库权限；current route 已核系统一般规则包含生成记录写入。答案却把本轮缺失的下游观测反写成“不涉及任务状态或日志落库”。生产持久元数据显示 answer audit 确实执行且启用了 fallback，因此根因不是多轮绕过，而是终审缺少这一类否定事实规则。

## 修复

- 识别“只有请求/响应”以及缺数据库、日志、状态观测权限的证据边界。
- 对回答中的“没有/未/不涉及/不写入/不记录”等下游否定逐句核 current route 和用户原文；没有直接支持则标记 `unsupported_evidence_negation`。
- 修订提示明确区分系统一般规则与本次实例结果；一般规则继续保留，本次结果只可写无法确认。
- 二次修订仍失败时删除完整违规句，追加通用未知边界，并用同一终审重新验证。

## 回归

`tools/fs-04-consult-conversation.logic.test.mjs` 固定生产原句，并覆盖：已核否定规则放行、用户直接提供否定事实放行、未知措辞放行、无证据写入失败拦截及 fallback 再审全绿。
