# CHG · consult 通用完整标题不得压过专用高分路由

- 日期：2026-08-26
- 关联：PD-04 路由检索
- 类型：生产路由回归修复

## 现象与根因

Audit 第 204 题完整出现“待审工作台”，同时明确询问批量通过中途失败、全成全败、流水、消息、HIS 回调、同批任务重试和事务边界。专用路由 `FLOW-BATCH-RETRY-01` 得分 143.707，宽泛 `WB-01` 只有 10.527；旧逻辑仍因完整标题无条件把 `WB-01` 强制置首，丢失专用已核事实和 `verifiedFacts` 终稿策略。

## 修复

- 完整唯一标题仍可强制切题，但其相关分必须至少达到当前最高候选的 50%。
- 若通用标题候选不足最高分的一半，则尊重高分专用业务路由，并将 `exactRouteTitle` 保持为 false。
- 保留既有 Q0014“处方标记”显式切题、FAQ 完整标题、部分标题和多标题比较题行为。

## 验证

- 新增“待审工作台 + 批量失败重试”生产形态回归，必须命中专用路由并透传 `verifiedFacts`。
- 继续运行 PD-04 全量路由测试与 FS-04 咨询回归；生产用第 204 题原文复测。
