## 变更

发布前结构审计新增跨行转折承接检查。答案开头或结论、判断等纯标题之后直接出现但、但是、不过、然而时，若没有上一条完整主张，触发全文修订；修订失败删除整句，不猜造被删前提。

## 原因

生产可见复测中，答案以“结论：但够继续只读排查”开头。每行单独看语法完整，但前半结论已在修订中丢失，形成文档级残句。
