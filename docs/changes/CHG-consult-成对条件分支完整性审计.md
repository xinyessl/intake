# CHG：咨询终稿审计成对条件分支完整性

- 日期：2026-08-14
- 关联 Spec：FS-04 AC-90
- 类型：缺陷修复 + 回归边界补全

## 变更

发布前结构审计新增成对条件标签检查。明确对照、比较或分支判断中，一致/不一致、是/否、有/无、成功/失败、存在/不存在、命中/未命中必须完整成对，或改为不承诺另一边的单一直接结论。修订失败时删除整组判断，不补造缺失分支事实。

## 原因

生产可见复测里，排查步骤只保留“一致”标签，另一种情况直接写成无标签判断。单句语法和 Markdown 均完整，但实施无法据此确定条件边界。

## 回归

`tools/fs-04-consult-conversation.logic.test.mjs` 覆盖缺“不一致”标签、完整成对标签和普通单一“一致”结论。
