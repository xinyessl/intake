# CHG · 咨询诊断草稿全清后的安全终稿

- 日期：2026-08-14
- 关联 Spec：FS-04 AC-102
- 类型：安全降级可用性防回归

## 变更

- 现场诊断草稿被发布前审计全部清理时，不再只输出机械安全拒答。
- route 命中时复用已核 answerFacts/mustNotConfuse 作为判断基线，再给 1~4 步通用只读留证；route miss 时只把具体业务事实标未知。
- 留证只查看已有页面、请求、响应、发生时间和脱敏截图，不新增技术名，也不为抓包重复未知业务动作。
- 用户只问第一步/先做哪个验证时，确定性 fallback 只给一个最小只读动作。

## 原因

生产可见 Chrome 复测中，诊断答案经过多重安全审计后只剩“未通过安全校验”，虽然没有臆造和副作用，却无法帮助实施继续排查。安全与可用性必须同时成立。
