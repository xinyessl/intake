# CHG · consult 答疑按问句意图分层并终审

- 日期：2026-08-25
- 类型：行为调整 + 生产回归
- 关联：FS-04 AC-131

## 变更

- 普通功能、范围、规则及普通“怎么实现”默认输出产品/业务语言；现场排查、复测、留证输出实施语言；仅明确问接口、字段、SQL、源码、Java 类、Mapper 或开发链路时展开研发细节。
- 实施答案先给业务结论与只读步骤/判断边界，技术事实末置“研发参考”；产品答案不输出源码名、类、表字段和接口链路，也不主动谈字段/状态值/Java 模型/研发参考/技术依据，或用“这轮资料未确认”收尾，业务结论与对象范围答清即止。
- 发布前语义审计新增受众违规，模型修订仍失败时执行确定性删除/末置；fallback 恢复 route facts 或唯一主接口时继续遵守受众与 focused scope。
- 同时扩展无证据资料缺失句式，拦截“未写成/未列为已确认事实或行为”等变体，避免检索片段缺失被写成 Spec 未定义。

## 边界

- 未修改被纳管项目的 Spec、fixture 或 gold。
- 不涉及数据库结构或持久层契约；生产发布与浏览器业务复测证据另行记录。
