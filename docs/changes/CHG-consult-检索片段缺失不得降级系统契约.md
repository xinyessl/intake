# CHG · consult 检索片段缺失不得降级系统契约

- 日期：2026-08-25
- 类型：纯 bug 修复（Spec 与期望答案已正确，不改产品 spec/fixture/gold）
- 范围：Spec 二阶段正文切片/MMR、consult 发布前事实审计与安全降级

## 根因

生产 Q0003 路由正确命中 current route，但同一长验收章节的后半分支被切到相邻块；固定每文件 3 段的 MMR 又让较弱目录/系统概览占用 Top5，导致模型只看到前半分支。安全 fallback 随后把“这次检索没带到”写成“说明书没写”。

## 修复

- 将普通章节切片目标从 1000 调整为 1400 字，减少连续 AC/成对分支被拆散。
- 当阶段一首候选明显强于第二候选时，允许强文件突破通常的 3 段上限使用 Top-N 预算；非强势路由仍维持跨文件多样性。
- current route 本轮实际注入的 direct evidence 进入终审事实作用域。
- 新增 `unsupported_evidence_absence`：没有 current route 明确 NEEDS-HUMAN/未定义/未覆盖证据时，禁止宣称 Spec、说明书或摘录未写/只确认到某处。
- 修订仍失败时删除错误缺失声明，恢复匹配的已核契约事实；本次实例是否准确执行继续标为未知。

## 回归

- 合成长 AC 章节固定相邻分支不丢。
- 真实 AUDIT AI-01 受限证据问法的 Top5 同时包含住院和门诊 VO 契约。
- 生产错误句命中新审计，fallback 恢复门诊契约并再次终审全绿。
- current route 明确 `NEEDS-HUMAN/未定义` 的真实缺口仍可照实回答。
