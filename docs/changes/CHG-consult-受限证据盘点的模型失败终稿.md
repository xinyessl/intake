# CHG · 受限证据盘点的模型失败终稿

- **日期**：2026-08-31
- **来源**：浏览器正式测试 Q0813。模型输出达到长度上限后，系统虽识别为 `partial_evidence`，但 verifiedFacts 发布口机械输出整张路由事实，漏答“当前证据能确认什么、哪些仍未知”。
- **类型**：纯缺陷修复；既有证据边界与业务规则不变，因此不修改 spec。

## 改动

- 对“当前只有/仅有某些证据，哪些成立、哪些仍需确认”的通用问法生成确定性终稿。
- 终稿固定区分“本轮能确认、已核说明、本轮未知、只读边界”，证据标签从当前问句提取，业务事实只来自当前命中路由。
- 禁止由接口状态、业务返回等局部观测外推服务已经部署或启动、外部依赖当前可用、后续链路已经完成。
- 普通事实题继续发布完整路由事实，不进入受限证据模板。
