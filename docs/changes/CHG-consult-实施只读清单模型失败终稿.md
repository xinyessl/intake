# CHG · 实施只读清单模型失败终稿

- **日期**：2026-08-31
- **来源**：浏览器正式测试 Q0815。用户要求“换成实施可以逐项照做的只读清单”，模型长度截断后却机械发布完整路由事实，没有形成可执行清单。
- **类型**：纯缺陷修复；业务事实和安全规则不变，因此不修改 spec。

## 改动

- 明确的清单化追问在 verifiedFacts fallback 下优先使用当前路由生成的确定性只读清单，不再被完整事实终稿抢占。
- 可将路由中的“依次核对 A、B、C”拆为连续编号步骤；只保留会改变判断的响应成功边界、查询覆盖缺口和日志异步边界，避免整张技术说明倾倒给实施人员。
- 收紧只读动作判定：单纯“核对提交编号”等证据对象不误报写操作；“核对后请重新提交”等先读后写指令仍会被拦截。
