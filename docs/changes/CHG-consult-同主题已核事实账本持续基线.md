# CHG · 同主题已核事实账本在部分证据下持续生效

- **日期**：2026-08-13
- **关联 spec**：FS-04 AC-50（行为边界补充，待人验收）
- **类型**：浏览器回归暴露的上下文连续性缺陷；补回归 AC

## 现象

同一会话前几轮已确认“PWRS 配置来自 usercenter `sys_config`、当前接口未按医院过滤”，后续实施说“目前只能确认请求发出，后端走到哪不知道”时，回答把整个配置来源与隔离边界重新降级为“说明书未覆盖”。安全留证步骤虽然正确，但抹掉了本主题已有事实。

## 修复

- 将同会话上下文从“只承接紧邻排查句”提升为同主题已核事实账本；“上午反馈、数据库/日志无权限、只靠页面/响应、还缺什么、复测”等只收窄本轮观测范围，不反向抹掉已核系统事实。
- 连续弱追问可回溯最近同主题的已核 route；不同 route 或新实体构成屏障。仅 route/Spec/源码进入账本，历史 assistant 自由文本不进入。
- normal/deep 默认提示词及服务端守卫固定答复顺序：持续有效的规则 → 本轮观测 → 局部未知 → 最少非破坏动作。
- PWRS 地图 DQ-012 补配置隔离/作用域自然问法，并明确“本次后端处理路径未知”不等于“配置来源与作用域未知”。
