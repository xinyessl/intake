# CHG：产品与实施可读问法不触发现改数据

- 日期：2026-08-26
- 类型：发布前答复安全修复
- 关联：`FS-04` AC-140

## 现象

用户只要求按产品和实施都能看懂的方式解释标记管理，答案却被归为实施诊断，追加研发接口、表名，并在“只读验证”下要求新建和删除标签。

## 修复

- 单独出现“实施”不再自动进入实施诊断模式；只有现场、排查、复测、留证、只读清单等真实诊断意图才进入该模式。
- 发布前审计在答案自称“只读”时扫描新建、编辑、删除、保存、提交、重试等指令，发现矛盾即按副作用拦截。
- 人工 route 可用完整、业务化的 `verifiedFacts` 终稿兜底，但仍必须通过其它事实与动作安全审计。

## 验证

- 新增 Q0061 回归：受众必须为 product，研发附录触发 `audience_technical_overreach`，伪只读写操作触发 `cross_actor_side_effect`，确定性终稿复审全绿。
