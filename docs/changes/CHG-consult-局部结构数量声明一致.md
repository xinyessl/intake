# CHG：咨询终稿审计局部结构数量声明一致

- 日期：2026-08-14
- 关联 Spec：FS-04 AC-94
- 类型：缺陷修复 + 回归边界补全

## 变更

发布前结构审计新增局部数量声明账本。同一小节内带确认、回复、补充、核对等动作的件、项、点、条数量不得互相漂移；冲突时触发一次修订，失败删除冲突数量文案并保留已有安全清单。

## 原因

生产可见复测中，标题声称“最少确认1件事”，正文紧接“请回复这两点”并列两项。既有表格/清单实际项数审计无法发现两个自然语言声明互相冲突。

## 回归

`tools/fs-04-consult-conversation.logic.test.mjs` 覆盖1件事到两点的漂移、单一两点声明和普通历史记录数量。
