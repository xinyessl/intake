# CHG · 生产承诺与路由否定事实矛盾校验

- **日期**：2026-08-31
- **来源**：浏览器正式测试 Q0822。问题询问“大屏有多数据库 Mapper 就能承诺生产兼容吗”，模型首句错误回答“直接承诺”，随后又说明不能证明生产兼容，形成核心结论自相矛盾。
- **类型**：纯缺陷修复；生产数据库证据边界和兼容口径未改变，因此不修改 spec。

## 改动

- 发布前新增基于当前路由事实的承诺边界矛盾校验。
- 仅当用户明确询问能否承诺、证明、认定或确认，且当前路由已有对应否定事实时，拦截无局部否定的肯定结论。
- 修订失败时删除冲突肯定句，并回到当前路由已核的“不能承诺/不能证明”边界。
- 不绑定具体题号、审方产品或数据库兼容文案；合法否定答案、普通开放式边界说明和有证据支持的肯定结论不受影响。
