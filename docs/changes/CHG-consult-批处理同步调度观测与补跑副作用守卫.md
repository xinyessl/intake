# CHG · 咨询批处理/同步/调度观测与补跑副作用守卫

- 日期：2026-08-13
- 关联 Spec：FS-04 AC-51
- 类型：行为边界补全（回归 AC）

## 变更

- normal/deep 默认提示词增加批处理/同步/调度安全规则：截图、最后成功时间、无新增和中断只算观测，缺预期频率、具体任务/平台、错误状态与 Owner 时不判断停调度、不归责。
- `/api/consult` 增加通用运行安全守卫，覆盖调度、定时任务、批处理、ETL、同步、导入及恢复/重跑/补跑/重触发自然问法。
- 恢复类动作统一视为可能有副作用；只有幂等/补偿、时间窗、范围、当前运行态、Owner/授权齐全时，才允许条件式给出受控执行方案。
- PWRS DQ-013 补充观测边界、受控执行事实和自然问法，不改 PWRS 业务代码、接口、数据库或真实调度配置。
