## 改动要点
- 布局改成「顶部橙色说明 banner 通栏 + 下方左标题导航（`.pnav`）/ 右单条编辑区（`.pedit`）」，各自 `overflow:auto` + `min-height:0`，外壳固定视口高度、无 body 全局滚动条（遵守全局 UI 规范第 3 条）。
- 左导航按现有分组（现场对话类 / 后台初判类 / 其它）做小标题分隔，每项显中文标题 + key 小灰字 + 「默认/已自定义」徽章，当前项高亮。
- 右侧只渲染当前选中的一条（说明 + 占位 chip + textarea + 保存 + 恢复默认 + 缺占位警告 + 字数计数），点左侧标题即 `renderEditor()` 重渲切换，**不再长滚动**。
- 默认选中「实施进件对话」（`intakeChatSystem`），无则第一条。
- 切换纯前端显隐/重渲，**不重新请求** `/api/prompts-config`（数据一次加载缓存在 `ITEMS`）。
- 保存/恢复默认后 `afterMutate()` 同步刷新**右侧 + 左导航对应项**的「默认/已自定义」徽章。
- 窄屏（≤860px）左导航退化成顶部横条（`max-height:34vh`），不挤爆编辑区。
- 复用 theme.css token（靛蓝 `--color-primary`）+ 现有卡片/tag 样式语言，未引新色。
