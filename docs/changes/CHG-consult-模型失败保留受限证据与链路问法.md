# CHG · 模型失败保留受限证据与链路问法

- **日期**：2026-08-31
- **来源**：浏览器正式测试 Q0848、Q0849。两题路由和题型识别正确，但模型输出被截断后，通用已核事实终稿抢先发布，分别漏掉“下一项最少只读证据”和“端到端链路/未知停点”。
- **类型**：纯缺陷修复；既有 route 事实和业务边界不变，因此不修改 spec。

## 改动

- 受限证据题的模型失败终稿保留用户本轮已给的页面现象与 requestId，并优先索取能够改变判断分支的下一项只读证据。
- 明确没有原始日志时，不声称查看过日志，也不由未取得的日志外推服务端分支、处理结果或后续状态。
- 链路题的模型失败终稿优先使用 current route 已核事实生成结构化链路，覆盖入口、接口/数据、外部依赖和资料未定义时的停止点。
- 普通事实题继续使用紧凑已核事实终稿；所有兜底仍经过完整事实、动作和结构审计。

## 验证

- Q0848 在 `MODEL_OUTPUT_TRUNCATED` 与 HTTP 429 下均发布最少只读补证，`finalViolations=[]`。
- Q0849 在模型截断下发布 route-scoped 确定性链路，保留外部依赖与未知停点，`finalViolations=[]`。
- 既有 AI、配置、主流程、XML、个人方案等 chain fallback 回归同步验证结构化终稿与事实作用域。
- Conversation + safe-final-stream：54/54 通过；`node --check`、`git diff --check` 通过。
