# CHG · 咨询文件制品分层验收守卫

- 日期：2026-08-13
- 关联 Spec：FS-04 AC-53
- 类型：回归边界补全

## 问题

PWRS Grok 4.5 浏览器 1000 题回归 Q66 中，模型对“导出返回 200 且文件非空”只做了表面判断，没有稳定给出 magic/扩展名/MIME、PDF/DOCX/XLSX/ZIP 结构和正文抽检，可能把 JSON/HTML 错误体或结构损坏文件误判为成功。

## 变更

- normal/deep 默认提示词增加下载/导出/附件/模板的分层验收契约。
- `/api/consult` 增加通用运行时守卫，锁定响应类型、字节长度、文件签名、容器结构和业务内容五层只读检查；格式未知时不硬猜。
- 换账号线索先固定条件，只读区分权限/数据范围/模板上下文与文件本体；不要求改权限、模板或业务数据。
- PWRS 模块地图 DQ-014/QR-EXPORT-EMPTY 补充自然问法、`answerFacts` 与 `mustNotConfuse`，不改写业务 Spec 事实。

## 风险与边界

- 本次只改咨询提示契约、诊断守卫与文档路由，不改 PWRS 业务代码、接口或数据库。
- 守卫不猜具体文件格式、导出路径、模板名和权限码；具体业务事实仍需 Spec/route/源码证据。
- 无持久层变更，真库冒烟不适用。
