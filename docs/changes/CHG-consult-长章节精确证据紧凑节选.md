# CHG · consult 长章节精确证据紧凑节选

- 日期：2026-08-25
- 关联 spec：PD-04 AC-10
- 类型：行为修复（人工 route 精确章节证据装载）

## 现象与根因

Q0009 的人工 route 已指向医嘱标记接口章节，但旧逻辑在完整定位前就将章节截成 1200/900 字，模型只看到章节开头的第一个接口，后续导出、表与软删除证据丢失。

## 修复

- `extractSection` 先按 Markdown 标题层级完整取出精确章节，不因前 900 字提前丢掉后半段。
- `routeEvidenceExcerpt` 在 800 字上限内紧凑重组已有证据：优先保留全部 HTTP 方法+路径，再保留状态、权限、数据、依赖等契约行；不生成新业务语义。
- 仍保持 route hit 数量 cap、受众分层和发布前审计规则不变。

## 回归证据

- `tools/pd-04-route.logic.test.mjs` 构造超过 900 字的 Q0009 形态章节，断言 800 字节选内仍有 4 个接口、`audit_ipt_collect` 和 `deleted=1`，且不越界到下一节。
- 相邻 consult / SSE / prompt / KB / Spec 两阶段检索套件作为行为回归。

## 风险边界

- 紧凑节选是确定性抽取与重排，不是摘要模型；无明确接口签名或契约关键词的长自然段仍可能按配额被舍弃。
- 生产真模型与浏览器复测证据另行记录。
