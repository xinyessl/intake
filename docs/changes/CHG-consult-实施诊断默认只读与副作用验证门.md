# CHG · consult 实施诊断默认只读与副作用验证门

- 日期：2026-08-13
- 关联 Spec：FS-04 AC-52
- 类型：行为边界补全（回归 AC）

## 变更

- normal/deep 默认提示词新增最高优先的通用非破坏诊断规则，覆盖 owner/权限、CRUD、反馈、收费、患教、审批、同步等现场主题。
- `/api/consult` 新增动态非破坏守卫：抓包本身虽是只读，主动新建、修改、删除、保存、提交、审批、签名、星标、打开致已读、补跑等触发动作仍视为有副作用；“只做一次/测试数据/可回滚”不构成豁免。
- 安全路径优先复用已有正常/异常记录、历史日志/审计、已经发生的请求响应和现有只读页面信息；刷新、纯前端只读页签、确认不会改变已读/状态的详情可用。
- 若确需副作用验证，须同时确认隔离测试环境或专用测试数据、执行授权、回滚/清理方案、幂等性与影响范围；条件不齐则升级开发或产品确认。
- PWRS 权限/归属 route 补只读排查 facts 与自然问法；业务代码、接口和数据库不变。

## 验证

- normal/deep 精确模板、服务端动态守卫、多主题正反例、权限/归属事实账本继承及显式新实体切题均有脱库自动化测试。
- 生产部署后使用官方 Chrome Browser Plugin 可见 UI 重跑 Q54–Q59 完整链，并覆盖只读既有记录、未经授权副作用、四项条件齐备、无副作用页面动作及显式换题。
