# CHG · 咨询终稿顶层步骤连续编号

- 日期：2026-08-14
- 关联 Spec：FS-04 AC-99
- 类型：生成后发布前结构防回归

## 变更

- 终稿审计新增顶层阿拉伯数字步骤连续性检查，覆盖跳号、重复编号与倒序。
- 修订失败时只按已有完整步骤的出现顺序连续重编号，不新增步骤、动作、字段或事实。
- 四空格嵌套清单与代码围栏中的编号不参与顶层审计；允许承接现场步骤从非 `1` 开始，但后续必须连续。

## 原因

生产可见 Chrome 复测中，回答正文事实与只读动作均正确，但步骤由 `1、2、3` 跳到 `5`，呈现为疑似缺段。原有守卫只覆盖未定义圈号引用，未覆盖顶层标题自身的连续性。
