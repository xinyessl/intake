# CHG · tag38 原因概率证据门与跨主体动作审计

- 日期：2026-08-14
- 关联：FS-04 AC-59/AC-60、Q0120–Q0128 浏览器回归
- 类型：咨询答疑通用安全与事实边界修复

## 变更

1. `consultNormal` / `consultDeep` 默认提示词新增原因概率证据门：没有 Spec 正文、源码、已核经验库或统计样本直接支持时，不再使用“最高频/最常见/通常/大概率”等词排序成因，只列不排序待验证分支。
2. 删除排查格式旧规则中“必须先说最高频原因”的反向诱导，改为先给已核结论和依据本轮证据可区分的分支；核心事实答清即停，不补模板变更、复制重存或行业惯例。
3. 运行时追加最终证据与概率语言审计，并把动作一致性扩展到实施、患者、对接方、运维和开发。改参数、报文类型、映射、配置后复测，或运维重跑、开发重试，不因执行主体变化而绕过只读/完整受控条件。
4. PWRS 患者号字段 route 补充窄自然问法“患者号少一位/字段对不上/丢位精度/数字还是字符串”，并保留患教身份、患者列表、token 等反例不抢路由。
5. 生产 Chrome 首轮暴露模型仍在答案中写“多半是服务端时区差”；r2 消除该词后，又暴露“转运维/开发改时区”的执行主体绕行。因此新增并扩展服务端发布前确定性语义校验：首轮完整草稿先留在服务端，命中无证据概率词或跨主体副作用动作（含改参数/映射/配置、改时区/系统时间/环境、复测/重跑等）时最多调用模型修订一次；修订仍失败则删除违规句并降级为安全边界。未经校验的草稿不先流给浏览器，结果写入 `retrieval.answerAudit` 并随 SSE 透出，便于生产回放。
6. r3 Chrome 回归中，模型把已核 `/pwrsapi/month/view/today` 缩成 `…/month/view/today`，并臆造无前缀的 `/month/view/today`。r4 将具体路径纳入同一发布前确定性审计：只允许当前问题或 route/Spec 事实中的逐字路径；前缀、路径段和尾斜杠任一漂移均触发一次修订，失败删除新路径并改为“该已核接口/当前请求”。
7. r4 Chrome 又暴露路径提取器把“服务器/JVM”中的 `/JVM` 当作路径，安全降级破坏原句。r5 将前置边界改为 Unicode 字母/数字边界，中文/英文两侧的普通斜杠短语均不进入路径集合，同时保留空格、标点或 `GET` 后真实绝对路径的检测。
8. r5 Chrome 验证路径已安全删除，但降级残留“GET 该已核接口”且把审计元说明展示给实施。r6 改为整体替换 HTTP 方法与未核路径，输出自然的“该已核接口/当前请求”；审计原因只保留在 `answerAudit`，不污染用户答复。
9. r6 Chrome 暴露同答同时出现合法完整路径和未核短前缀时，全局字符串替换会把合法长路径内部一起改坏。r7 改为带前后路径字符边界的 token 替换：短前缀只在独立出现时降级，已核完整路径逐字保留。
10. r7 Chrome 暴露模型把 Unicode 省略号换成 ASCII `.../path` 绕过检测。r8 将 `…/path`、`.../path` 与合理的连续点+空格+斜杠变体（如 `.. /path`）都作为完整缩写路径 token 审计并整体替换，普通句号、版本号、IP 和已核完整路径边界保持不变。
11. r8 Chrome 的今天视图答复主线正确，却从相邻检索片段引入 `/comm/*`、外部调度与补跑。r9 新增当前事实作用域审计：只允许用户本轮和当前/继承 route facts/refs 的实体与路径；通配路径同样受控，越界触发一次修订，失败删除整句，诊断仅落 `answerAudit`。

13. r10 Chrome 在今天视图排查末尾自行引入“患者 hospitalId/patientId/visitId 三元身份”作排除说明。r11 将相邻业务实体词族与强业务标识符统一纳入当前事实作用域审计：自动识别 camelCase 的 `*Id/*Code/*Status/*No/*Type` 和 snake_case 复合标识符，仅本轮问题或当前/继承 route facts/refs 逐字出现时放行；显式新实体重路由后使用新事实，无关主题整句删除，裸 id/code/status 与 HTTP/JSON/JWT 等共享词不误拦。
