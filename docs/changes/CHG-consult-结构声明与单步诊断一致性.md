# 咨询终稿结构声明与单步诊断一致性

- 发布前新增文档级结构基数审计：二/三/四边、项、份或个对照的声明必须与按行列项表格的完整数据行数一致；横向同数列表不误判。
- 新增空引导句审计：“例如：/如下：/包括：/分别为：”后直接跳到下一步骤、标题或结束时触发一次不新增事实的全文修订。
- 用户明确只问先做哪个验证或第一步做什么时，终稿只保留一个最小只读验证；多个顶层编号步骤触发修订。
- 一次修订仍失败时，删除数量声明与对应整表、空引导及后续步骤；不通过补造字段、来源、示例或观测点凑结构。
- 这是生产可见 Chrome 回归暴露的边界遗漏；业务事实、接口、数据库和 PWRS 代码均未改变。
