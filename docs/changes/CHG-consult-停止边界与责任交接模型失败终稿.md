# CHG · 停止边界与责任交接模型失败终稿

- **日期**：2026-08-31
- **来源**：浏览器正式测试 Q0830。问题要求说明“停在哪个边界并交给谁继续”，模型长度截断后 verifiedFacts 回退只发布完整事实，没有直接给出停止点和交接责任。
- **类型**：纯缺陷修复；既有证据边界与责任范围不变，因此不修改 spec。

## 改动

- 明确的“停止边界 + 交给谁”问法在模型失败时优先发布专用确定性终稿，不再被完整事实答案抢占。
- 停止点只取当前路由明示的证据或禁止边界；责任角色只从当前路由事实中枚举。
- 对路由明示的角色，逐一给出其继续核对的只读证据；路由未定义角色时明确停住，由用户指定责任人，禁止猜产品、研发或接口负责人。
- 固定禁止改数据、重放、重复提交和重试。

## 验证

- Q0830 长度截断回退明确给出停止点、DBA/数据库负责人及生产 schema、迁移记录和版本的只读核对范围。
- Q0030、Q0285 和通用无角色场景均安全回答“资料未定义，由用户指定”，未猜责任人。
- 同路由普通事实、chain 和非交接 context followup 保持原行为。
- Conversation + safe stream：54/54 通过；`node --check`、`git diff --check` 通过。
