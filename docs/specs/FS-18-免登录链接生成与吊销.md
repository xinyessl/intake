> **公共机制见导读 FS-06**（token 签发/验签、`data/link-secret` 密钥文件、`LINK_OK` 白名单、访客身份识别）。本条只规约**运营端签发链接**（A 组）与**链接吊销/有效期**（F 组）；访客侧链路见 FS-19。

## 1. 用户故事 / 目标
作为**运营/维护人员**，我要给某产品生成一条**免登录提交链接**（带预置的现场 site / 版本 ver / 可提交类型 type / 有效期 days），发给现场临时人员或无账号用户；并能在需要时让链接失效（单条靠有效期到期、批量靠换密钥），以便无账号场景规范收件且链接可控。

## 2. 范围
**包含：**
- **生成端（运营端调用 · 已有 `/api/submit-link`）**：管理员传 `project`（必填）+ `site`/`ver`/`type`/`days`（可选），返回 HMAC 签名 token + 相对路径 `path` + field 域绝对地址 `url`（FS-08）+ `days`。
- **签发权限**：`/api/submit-link` **仅管理员**可调（不在 `LINK_OK`/`FIELD_OK` 白名单 → `authGate` deny-by-default 拒非管理员/访客）。
- **吊销/有效期**：单条靠 token 的 `exp` 到期自动失效；批量靠更换 `data/link-secret` 密钥文件令全部旧 token 验签失败；密钥文件不存在时首次自动生成。

**不包含：**
- 免登录链接**生成 UI**（产品管理页的"生成链接"弹窗）——属产品管理 PD 侧，本条只规约 `/api/submit-link` 契约。
- token 的**逐条吊销列表 / 管理台**（真实实现无 token 库存储，无法按单条主动吊销）→ 见 §6 NH-2。
- 访客侧的打开/提交/校验/越权（在 **FS-19**）。

## 3. 验收标准（AC · Given-When-Then · 每条必须可自动化判定）

### A. 生成免登录链接（`POST /api/submit-link` · 运营端/管理员调用）
- **AC-A1** Given 管理员已登录 When `POST /api/submit-link {project:<存在的产品id>}` Then 返回 `200 {ok:true, token, path:"/submit.html?token=<token>", url:<绝对或回退相对>, days:365}`（`days` 缺省 365）；`token` 形如 `<b64u payload>.<b64u hmac>`（含一个 `.`）。〔2026-09-02 校正：真实响应含 `url` 字段（server.mjs L6063）——`FIELD_ORIGIN` 配了则为 field 域绝对地址、未配则回退相对 `path`（见 FS-08 AC-18）；`path` 恒为相对路径不变。〕
- **AC-A2** Given `POST /api/submit-link {project:"__不存在__"}` Then 返回 `400 {ok:false, error:"项目不存在"}`（`projById(b.project)` 为空即拒，不签发 token；server.mjs L6056）。
- **AC-A3** Given `POST /api/submit-link {project:<id>, site:"XX医院", ver:"v1.2.0", type:"bug", days:30}` Then token 解出的 payload 含 `{project:<id>, site:"XX医院", ver:"v1.2.0", type:"bug", exp:<约30天后的毫秒时间戳>}`（`exp = Date.now()+days*86400000`）。
- **AC-A4** Given `days` 传 `0` / 负数 / 缺省 / 超大 When 生成 Then `days` 被夹到 `[1,3650]`（`Math.min(3650,Math.max(1,+b.days||365))`）：`0`→`+0||365`=365、`-5`→`+(-5)`=-5 真值故 `Math.max(1,-5)`=1、缺省→365、`9999`→3650。
- **AC-A5** Given `type` 传非 `bug|requirement|consult` 之一（如 `"任意"` 或缺省）When 生成 Then token 内 `type` 记为空串 `''`（`(b.type∈{bug,requirement,consult})?b.type:''`），表示"类型不锁定，访客可自选"。
- **AC-A6** Given 非管理员（`pm`/`impl`）或访客 When 调 `POST /api/submit-link` Then **被拒**——`/api/submit-link` 不在 `LINK_OK`/`FIELD_OK` 白名单，`authGate` deny-by-default 返回 `403 {error:"forbidden"}`（登录现场账号）/ `403 forbidden`（访客）。

### F. 链接吊销 / 有效期
- **AC-F1** Given 单条链接需失效 When 其 `exp` 到期 Then 该 token 自动失效（`verifyToken` 见 `exp<Date.now()` 返 `null`，等同 FS-19 AC-D1），无需后台操作——"有效期"即单条链接的吊销机制。
- **AC-F2** Given 需**批量吊销全部**已发链接 When 更换密钥文件 `data/link-secret`（删除令下次 `linkSecret()` 重新随机生成 / 或替换其内容）Then 所有旧 token 的 HMAC 验签全部失败（`verifyToken` 返 `null`，等同 FS-19 AC-D2），一次性失效——这是真实实现下的"整体吊销"手段。
- **AC-F3** Given `data/link-secret` 不存在 When 首次调用 `linkSecret()` Then 自动生成 24 字节随机 hex 写入该文件（`crypto.randomBytes(24).toString('hex')`）；同一进程后续复用同密钥，签发/验签一致。

## 4. 接口契约（对齐真实 server.mjs · 逐字段核过）

### 4.1 生成链接 `POST /api/submit-link`（server.mjs L6053-6065 · 仅管理员，authGate deny-by-default）
```
POST /api/submit-link
body: { project:string(必填,产品id), site?:string, ver?:string,
        type?:'bug'|'requirement'|'consult'(其它→''), days?:number(1..3650, 缺省365) }
→ 200 { ok:true, token:string, path:"/submit.html?token=<token>",
        url:string(FIELD_ORIGIN 配了=field 域绝对地址, 未配=回退相对 path), days:number }
   或 400 { ok:false, error:"项目不存在" }（projById 为空 · server.mjs L6056）
   或 400 { ok:false, error:"bad json"/"请求体过大" }（body 异常）
错误码：403 forbidden（非管理员——不在 LINK_OK/FIELD_OK，authGate 拒）
```
- **签发逻辑**（`signToken` · L5893）：`payload = {project:proj.id, site:trim(site), ver:trim(ver), type:t, exp:Date.now()+days*86400000}`；`token = b64u(JSON(payload)) + '.' + b64u(HMAC-SHA256(payload_b64u, linkSecret()))`。
- `days` 夹取：`Math.min(3650, Math.max(1, +b.days||365))`（L6057）。
- `type` 归一：`(b.type==='bug'||'requirement'||'consult') ? b.type : ''`（L6058）。
- **绝对地址**（L6060-6062，FS-08 §4③）：`relp = '/submit.html?token='+token`；`absu = FIELD_ORIGIN ? (FIELD_ORIGIN.replace(/\/+$/,'')+relp) : relp`；响应 `path:relp, url:absu`。

### 4.2 密钥文件（`linkSecret` · server.mjs L5891）
```
data/link-secret：读文件 → 存在返内容；不存在 → crypto.randomBytes(24).toString('hex') 写入并返回
更换/删除该文件 = 整体吊销所有旧 token（AC-F2）
```
- token 签发/验签公共机制详见导读 **FS-06 §1**。

## 5. 数据契约
> **token 无库存储**——见导读 FS-06 §1/§4。本条不新增表/列。
- **token**：`b64u(JSON(payload)) + '.' + b64u(HMAC-SHA256(...))`；payload `{project,site,ver,type,exp}`。
- **密钥文件 `data/link-secret`**：24 字节 hex；生命周期见 FS-06 §1④。
- 真实库 5 表（`db.mjs`）**无** `intake_submit_link` 表。

## 6. 业务规则 / 非功能
- **生成端权限**：`/api/submit-link` 仅管理员可调（`isAdmin`，含遗留 `dev`）——非管理员/访客被 `authGate` 拒（AC-A6）。
- **不可枚举**：token 含 HMAC-SHA256 签名，无密钥无法伪造/枚举有效 token。
- **可吊销**：单条靠 `exp` 到期（AC-F1）；批量靠换 `data/link-secret`（AC-F2）。真实实现**无按单条主动吊销**能力（无 token 库）→ 见 NH-2。
- **性能**：token 签发为无 IO 的 HMAC 计算（密钥文件仅首次读、进程内复用），开销可忽略。

**已裁决（2026-07-22 · 见导读 FS-06 尾）：**
- **NH-2 单条主动吊销 → 不做**：无 token 库，靠 `exp` 到期或换 `data/link-secret` 整体失效；**不引入 token 库/黑名单、不改库**（遵护栏）。
- **NH-3 有效期 → 保持 `days=365` 缺省、上限 3650**：不改现状。
- **NH-4 绑定范围 → 保持单产品 + 单现场**：一条 token 绑单一 `project` + 单一 `site`（可空）；不做多医院/多产品、不强制必须绑 site。
- **NH-5 验收人**：`owner_human` 待指派（非阻断）。
