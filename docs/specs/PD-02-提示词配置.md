## 1. 用户故事 / 目标
作为**运营后台管理员**，我要在后台**把 server.mjs 里全部 AI 系统提示词外部化成可配置项、并整段原始模板编辑**（自行保留 `{{占位变量}}`），**以便**不改代码、不重新发版就能调优 AI 的话术 / 路由纪律 / 回复规则；同时**默认行为零变化**（未改时用内置默认=现原文，改了才生效），且**和确定性建单/解析死耦合的结构块（intake-plan JSON）由系统强制注入、用户改不坏**。

## 2. 范围
- **包含**：
  - 外部化 server.mjs 全部 5 个 AI 系统提示词为可编辑模板（见 §5 清单）；抽默认值为 `DEFAULT_PROMPTS` 常量（= 现原文逐字）。
  - 配置文件存储 `data/prompts.json`（gitignored，同 `data/model-api.json` 范式）+ 运行时读带轻缓存 + 缺失/某 key 缺失/解析失败**回落默认**。
  - 运营后台新增页面 `public/prompts.html`（整段 textarea 编辑 + 占位参考清单 + 恢复默认 + 保存即生效）+ 导航「提示词配置」入口（AI 引擎组，挨着「模型配置」）。
  - 后端端点 `GET /api/prompts-config` + `POST /api/prompts-config-save`（admin 域）。
  - 安全护栏：`intake-plan` 的 JSON 结构块作 `{{intakePlanSchema}}` **系统注入占位**（不开放自由文本）；条件分支拆成干净整段模板（consult.deep/normal）或注入占位（intakeChat 的 subBlock/std/actionBlock/archivedBlock）。
  - 占位缺失 → **非阻塞警告**（允许保存，明确红字提示）。
- **不包含**：改 `callModel`/`callModelStream` 传输层；改现场 `field.html`；把「客户/模型 API Key」等非提示词配置纳入本页；提示词版本历史/回滚（本期只留「当前生效 + 恢复默认」）。

## 3. 验收标准（AC · Given-When-Then）
- **AC-1（列全部 + 整段编辑）** Given 管理员进 `/prompts.html` When 页面加载 Then 列出**全部 5 个** AI 提示词（分组：现场对话类 / 后台初判类 / 其它），每个卡片含标题 + 说明 + **大 textarea 整段模板**（含 `{{占位}}`）+ 可用占位清单 + 保存 + 恢复默认；未改的标「默认」，改过的标「已自定义」。
- **AC-2（存储 + 运行时读 + 缺失回落默认 · 行为不变 · 最重要回归）** Given `data/prompts.json` 不存在 / 某 key 缺失 / 解析失败 / 某 key 空串 When server 渲染对应提示词 Then **回落 `DEFAULT_PROMPTS`**，且 `renderPrompt(默认模板, vars)` 的输出 **逐字等于**改造前各 `*System()` 的原始输出（多组输入组合断言）；Given 某 key 被自定义 Then 该 key 用配置值、其余仍默认。
- **AC-3（占位注入 + intake-plan 结构块安全护栏）** Given 任意提示词模板 When server 渲染 Then 把 `{{占位}}` 替换成运行时计算值（产品名/版本/spec 索引/子系统清单/条件块）；`{{intakePlanSchema}}` 恒被注入完整 `intake-plan` items JSON 结构块——**即使用户整段改写 intakeChatSystem，渲染结果仍含合法建单结构块**（解析不崩）。
- **AC-4（占位缺失非阻塞警告）** Given 用户保存的模板缺了某**必需占位**（如 intakeChatSystem 缺 `{{intakePlanSchema}}`、consult 缺 `{{specExcerpts}}`）When 保存 Then **允许保存**并返回 `warnings`（缺失占位清单），前端红字提示「缺少必需占位 X，可能导致 Y 失效」；不缺则无警告。
- **AC-5（恢复默认）** Given 某提示词已被自定义 When 点「恢复默认」（或提交空模板 / 提交与默认逐字相同的内容）Then 从 `data/prompts.json` 删该 key、回落默认、`isDefault=true`。
- **AC-6（端点契约 · admin 域）** Given 非管理员（现场账号 / 访客链接）When 调 `/api/prompts-config(-save)` Then 被 `authGate` 挡（403/401）——该路径**不进** `LINK_OK`/`FIELD_OK`/`FS08_FIELD_API`；管理员可正常读写。

## 4. 接口契约
> admin 域，鉴权口径同 `/api/model-config`（未进 FIELD_OK/LINK_OK/FS08 → `authGate` 对非 admin 自动 403/401）。

### GET /api/prompts-config
- 出参：`{ ok:true, items:[{ key, label, desc, group, template（当前生效值=配置或默认）, isDefault, placeholders:[{name,desc}], requiredPlaceholders:[…], missingRequired:[…], maxLen }] }`

### POST /api/prompts-config-save
- 入参（单条）：`{ key, template }` 或 `{ key, reset:true }`（恢复默认）；（批量）：`{ items:[{key,template,reset?}] }`
- 行为：`reset` 或空模板 或与默认逐字相同 → 删该 key（回落默认）；`template.length > maxLen(20000)` → 该条 `ok:false`；缺必需占位 → 仍保存、`warnings` 带缺失清单；未知 key → 该条 `ok:false`。写 `data/prompts.json` + 失效缓存。
- 出参：`{ ok:<全部成功>, results:[{key,ok,error?,warnings?,reset?}], updated:[{key,template,isDefault,missingRequired}] }`

## 5. 数据契约
- **`data/prompts.json`**（gitignored 运行时存储，非 MySQL）：`{ "<key>": "<用户自定义模板字符串>", ... }`——只存被改过的 key（未改走 `DEFAULT_PROMPTS`，天然回落）。默认值进代码 `prompts.mjs` 的 `DEFAULT_PROMPTS` 常量。**不新增/改任何 MySQL 表列**。
- **纳入的 5 个提示词 key**（清点自 `server.mjs` `system:` 调用点 + `你是「` 字符串）：
  | key | 触发 | 占位 | 必需占位 |
  |---|---|---|---|
  | `analyzeSystem` | 后台工单「AI 分析」初判（只输出严格 JSON） | projectName, versionSuffix, specIndex | — |
  | `intakeSystem` | 续聊/intake-reply 进件助手初判 | projectName, versionParen, specIndex | — |
  | `intakeChatSystem` | 现场对话式进件（产出 intake-plan 建单计划） | typ, mergedLabel, projectName, versionParen, subBlock, specIndexBlock, std, **intakePlanSchema🔒**, actionBlock, archivedBlock, typeRule | `intakePlanSchema` |
  | `consultNormal` | 答疑/找 spec（普通版） | projectName, subsSentence, specIndexBlock, specExcerpts, kbBlock | `specExcerpts` |
  | `consultDeep` | 答疑/深入思考（附源码片段） | projectName, subsSentence, specIndexBlock, specExcerpts, codeExcerpts, kbBlock | `specExcerpts`, `codeExcerpts` |
  | `kbFromConsult` | 咨询对话整理成经验库条目（只输出 JSON） | （无） | — |
  > `consultSystem` 因有「深入思考」大模式分支，拆成 `consultDeep`/`consultNormal` 两个干净整段模板（各自完整规则文本）。

## 6. 业务规则 / 非功能
- **权限**：admin 域（`authGate` 挡非 admin）；不进 field 白名单（AC-6）。
- **安全护栏**：`{{intakePlanSchema}}` = `prompts.mjs` 的 `INTAKE_PLAN_SCHEMA` 常量（含 items JSON 结构 + action 字段），**server 强制注入、用户改不到内容**；即便用户删了该占位，也只是 warnings（建单块不出现→建单可能失效），但不会把结构改坏导致解析崩。
- **默认行为零变化（硬要求）**：`DEFAULT_PROMPTS[key]` 逐字等于改造前 `*System()` return 的模板，占位填充结果与原逐字一致（`tools/pd-02-prompts.logic.test.mjs` 断言）。
- **缓存**：运行时读带 mtime 轻缓存；保存 `writePromptsCfg` 后失效缓存、下次读最新（同 readModelCfg 思路）。
- **校验**：模板长度上限 20000 字（前端 maxlength + 后端 `PROMPT_MAX_LEN` 双层）；占位缺失非阻塞警告。
- **留痕**：本期不做提示词改动审计（NEEDS-HUMAN 若需）。
