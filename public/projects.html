新增产品
贴 GitLab 组地址「解析」自动带出 id / 名称 / 子系统（含中文描述）
贴产品的 GitLab 仓库 / 组地址，点「解析」自动带出 id、名称、子系统（含中文描述）。贴组地址 → id 取组名、组下各仓为子系统；贴单个仓（.../xxx.git）→ id 取仓名。保存时后端克隆各仓，用于读版本(git tag) / spec。需先在右上「Git 集成」配 host + token。
主键，小写字母 / 数字 / 连字符，1~40 位，以字母或数字开头。保存后不可改（改 id = 删旧建新）。
